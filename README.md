# tg-assistant-bot

Личный Telegram-ассистент поверх headless-мозга OpenClaw. Пишешь боту в чат —
отвечает агент, крутящийся на домашней машине. Доступ только у владельца, все
остальные молча игнорируются.

## Запуск

```
pip install -r requirements.txt
```

Дальше `run.bat` (или `python bot.py`).

В `.env` нужны `BOT_TOKEN` от @BotFather, `OWNER_ID` — твой Telegram-id
(узнать: команда `/id` у бота) и `OPENROUTER_API_KEY`, если нужна расшифровка
голосовых. Пути к `node` и `openclaw.mjs` определяются сами, если не заданы
явно.

Отдельно должен быть поднят гейтвей OpenClaw — он и делает настоящий вызов
модели.

## Как это устроено

Telegram-соединение принадлежит **этому** боту: один токен — один поллер.
Слэш-команды, меню и инлайн-кнопки обрабатываются здесь и в OpenClaw не уходят
никогда. Наружу, к агенту, отправляется только обычный текст (и голос после
расшифровки), а обратно возвращается его ответ.

Мост (`openclaw_brain.py`) дёргает `node openclaw.mjs agent ... --json` в обход
`.cmd`-обёртки — чтобы текст с пробелами, кавычками и переносами строк уезжал
в argv без порчи. Сам процесс бота модель не вызывает, он только реле.

## Команды

| | |
|---|---|
| `/menu` | кнопки-функции |
| `/new` | начать новый диалог |
| `/help` | помощь |
| `/id` | показать свой Telegram-id |
